## 완료 조건

1. 저장소·상위 변경·SDK·의존성 확인: 완료. upstream feature는 기준의 조상이며 migration04/05의 ARM64 CI·서명·메타데이터 수정을 참고했다. 기능 전체 병합은 하지 않았다.
2. ARM64 앱: 완료. 353개 기존 테스트 통과, sample로 ARM64 프로세스 확인. 실제 ASS 편집·저장·재열기, 스타일·태그 보존 확인. 앱에서 VideoToolbox 영상과 PortAudio/CoreAudio 스트림 확인.
3. 한글 입력기 수정·실제 앱 재검증: 완료. 첫 포커스·재포커스 한글 조합은 사용자 확인. 이후 보고된 한국어 ⌘A 문제는 Cocoa/wx 키 코드 소실로 재현하여 수정했다. 수정 전 28개 중 4개 실패, 수정 후 ASan 포함 28개 통과. 별도 위치 앱에서 실제 ⌘A·⌘C·⌘V·⌘Z·⇧⌘Z, Lua 매크로 10개, Retina 좌표와 음향 타이밍 저장을 직접 확인했다. 사용자는 수정 후 한글 상태의 단축키·받침 수정·재생도 정상이라고 최종 확인했다.
4. 배포 번들·DMG·CI: 완료. 최종 SHA1963a07cedfe46905e23292cdc3b06f39be37ba8의 앱·DMG·대응 소스를 생성했다. 로컬과 실제 ARM64 CI에서 마운트된 DMG의 아키텍처·의존성·서명을 통과했고, DMG에서 꺼낸 앱을 별도 위치에서 실제 실행했다. CI run34817454400은 모든 검사와 산출물 4종 업로드 성공.
5. 최종 기록: 완료. 한국어 보고서·절대 산출물 경로·재현 명령·실제 검증 결과·제한을 대조했다. 최종 CI 원문과 GUI/아키텍처 증거를 보존하고 문서 커밋으로 전달한다.

## 확인된 수정 대상과 선택

- 기존 CI는 macos-13이며 ARM64 실행 검사 없음. ARM64 러너 전용 작업 필요.
- 번들 Info.plist는 x86_64/i386만 명시한다. 실제 빌드 아키텍처로 치환 필요.
- tools/osx-fix-libs.py는 첫 rpath만 사용하고 /opt 및 /usr/local만 수정하여 빌드 경로 누락 가능. 전이 의존성 해결 및 실패 검사 필요.
- tools/osx-bundle.sh의 sudo 제거와 공백 경로, 최종 앱 서명 필요.
- 기존 LuaJIT 포트는 ARM64 및 LUAJIT_ENABLE_LUA52COMPAT를 지원한다. 실제 런타임 확인 및 리비전 고정 필요.
- BestSource R8의 libp2p Bitbucket URL 실패. 프로세스 범위 Git URL 치환으로 공식 GitHub 이전 주소를 사용한다.
- 기존 BestSource/FFMS2와 호환되는 FFmpeg 7.1.2를 .deps에 소스 빌드한다. VideoToolbox와 AudioToolbox를 활성화한다.
- 영상: BestSource의 프레임 정확성 및 VideoToolbox 경로를 먼저 검증하고 FFMS2도 보존한다. 오디오: PortAudio/CoreAudio. FFTW 스펙트럼·Hunspell·uchardet 보존.
- 선택 기능 AviSynth/VapourSynth는 별도 런타임이 필요한 플러그인 입력이며 첫 독립 번들에서는 제외한다. 일반 자막·영상·오디오 기능은 유지한다.
- wxWidgets 3.3.3 공유 라이브러리의 비공개 wxNSView 심볼로 기존 Scintilla IME 링크가 실패하여 .deps에 wxWidgets 3.2.9를 정적 빌드했다. 기존 편집기와 IME 구현을 유지했다.
- 최소 macOS 26.0: ICU 등 실제 Homebrew 의존성의 LC_BUILD_VERSION 제약을 확인. FFmpeg와 wxWidgets는 프로젝트 내부에 소스 빌드한다. M1 포함 Apple Silicon을 대상으로 하며 CPU 특화 플래그 없음. 이전 macOS는 미지원.
- BestSource VideoToolbox는 실제 하드웨어 프레임, 240개 전체 프레임의 CPU 대비 내용·PTS 일치, 240개 무작위 탐색, 취소·미지원 코덱의 CPU 재시도까지 통과했다.

- 프로젝트 .venv에 Meson 1.7.2, Ninja 1.13.0, CMake 3.31.6 설치. npm 사용 없음.
- Homebrew에 wxwidgets, libass, fftw, hunspell, uchardet, xxhash 및 json-c/libunibreak 설치. 의존성 jpeg-turbo/libtiff가 함께 갱신되었으며 이전 Cellar 파일은 정리하지 않았다.

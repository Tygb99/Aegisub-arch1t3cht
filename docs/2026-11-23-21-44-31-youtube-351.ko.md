# 공식 3.5.1 바탕 Aegisub YouTube

기반은 공식 `v3.5.1`, 커밋 `088ca6caa878209e279871f8897273f49342372b`입니다.
`a5df9a31d`부터 `847fe1053`까지의 YouTube 변환·진단·편집용 가져오기·내보내기·
미리보기 기능과 PR #6(`4579de850`)을 옮겼습니다. 공식판에 이미 있는 CMake 정책,
더는 쓰지 않는 Bitbucket 의존성, 바뀐 Windows 설치 의존성 구조에 대한 옛 수정은
제외했습니다.

일반 메뉴는 `src/libresrc/default_menu_platform.json`으로 옮겨졌으며 macOS는
전용 메뉴를 유지합니다. 명령 등록은 `std::make_unique`를 씁니다. 연결된 자동화
스크립트는 공식 동의 창을 거칩니다. YouTube 변환이 동의 창을 건너뛰거나 자막의
스크립트를 실행하지 않습니다.

## 빌드

공식 `README.md`와 `.github/workflows/ci.yml`의 설정을 따릅니다. 배포용 맥 ARM64는
`macOS arm64 Release` 설정(`tools/macos-release.ini`, 소스 의존성, FFTW 단계 포함)을
씁니다. Meson·Ninja·CMake·nasm·`tools/youtube/global.json`에 지정된 .NET SDK·Ruby가
필요합니다.

`build`에 본체를 설정하고 빌드한 다음:

```sh
bash tools/youtube-package.sh
```

`artifacts`에 임시 서명한 별도의 `Aegisub YouTube.app`을 만들고 helper를 넣습니다.
회귀 검사와 소스·시험 자막도 동봉합니다. `/Applications/Aegisub YouTube.app`은
바꾸지 않습니다. Developer ID 서명과 공증은 별도 발행 단계입니다.

Windows x64에서는 공식 MSVC 설정으로 본체를 빌드한 다음:

```powershell
.\tools\youtube-build.ps1 -OutputDirectory "$PWD\build\youtube"
```

helper 폴더는 `aegisub.exe` 옆에 둡니다. 포터블·설치판에도 함께 들어갑니다.
외부 YouTube 미리보기에는 Chrome 또는 Edge와 일치하는 수동 자막 트랙이 필요합니다.

화면 시험은 무해한 Lua 스크립트를 연결한 ASS를 엽니다. 거절하면 실행되지 않는지,
다시 열고 동의하면 매크로가 생기는지 봅니다. 이어 YouTube 창에서 시험 자막을
변환하고 내보냅니다.

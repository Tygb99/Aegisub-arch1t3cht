# Aegisub YouTube on 3.5.1

Base: official tag `v3.5.1`, commit `088ca6caa878209e279871f8897273f49342372b`.
The YouTube conversion, diagnostics, editable import, export, and preview changes
are ported from `a5df9a31d` through `847fe1053`, plus PR #6 (`4579de850`).
Obsolete fork-only dependency fixes are omitted: upstream already supplies the
CMake policy, no longer uses the Bitbucket dependency, and has replaced the
Windows installer dependency layout.

The platform menu is now `src/libresrc/default_menu_platform.json`; macOS retains
its own menu. Native command registration uses `std::make_unique`. Local Automation
script loading continues through the upstream consent prompt. YouTube conversion
does not bypass it or execute the scripts referenced by a subtitle.

## Build

Use the official `README.md` and `.github/workflows/ci.yml` build configuration.
For a distributable macOS ARM64 build, use the `macOS arm64 Release` configuration,
including `tools/macos-release.ini`, source dependency fallbacks, and the FFTW step.
Meson, Ninja, CMake, nasm, the .NET SDK selected by `tools/youtube/global.json`,
and Ruby are required.

After configuring and building the native app in `build`:

```sh
bash tools/youtube-package.sh
```

This creates a separate ad-hoc signed `Aegisub YouTube.app` in `artifacts`, bundles
the helper, runs the helper regression tests, and includes source and fixtures.
It does not replace `/Applications/Aegisub YouTube.app`. Developer ID signing and
notarization are separate release steps.

On Windows x64, build the native app with the official MSVC configuration, then:

```powershell
.\tools\youtube-build.ps1 -OutputDirectory "$PWD\build\youtube"
```

The helper directory must sit beside `aegisub.exe`. The portable and installer
packaging steps include it. Chrome or Edge and a matching manual caption track
remain necessary for the external YouTube preview.

```sh
ruby tools/youtube-test.rb
git merge-base --is-ancestor e4099055711cce327840870c050ce46e58f4aee0 HEAD

```

For manual QA, open an ASS referencing a harmless local Lua script. Decline the
prompt and confirm no script ran; reopen, consent, and confirm its macro appears.
Then open the YouTube dialog and convert/export a sample subtitle.
